# spring-laya

Planning tracker for Laya support in [spring-ai-typesafe](https://github.com/spring-ai-community/spring-ai-typesafe). There is no code here.

The goal is for Spring to support [Laya](https://github.com/NandhaKishorM/laya) the way it supports TypeSafe Jev. The changes land upstream, in spring-ai-typesafe and in Laya itself. This repository's issues hold the map (label `wayfinder:map`) and its tickets.
